# Development

- Read README.md and HANDOFF.md; inspect git status before editing.
- Keep this repository independent of other apps.
- Never commit .env, backups, credentials, or user/course data.
- Preserve database and moodledata. Never reset them without explicit permission.
- Pin sources and Docker digests; match STACK and GoeMaxima versions.
- Verify setup, repeat setup, start/stop and STACK healthcheck after infrastructure changes.
- Record actual tests and outstanding checks in HANDOFF.md, distinguishing CLI from browser verification.
- Use repository-relative paths in public docs.
